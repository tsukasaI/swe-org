# cszap

## arai60/

LeetCode の問題を Go で解くコーディング面接練習ディレクトリ。
問題リスト: https://1kohei1.com/leetcode/

### 練習の進め方

- 面接官・講師役としてコードレビュー・ディスカッションを行う
- ディスカッション時は答えを先に出さず、質問を投げかけて候補者（ユーザー）の回答を待つ
- 計算量（Time/Space complexity）は提示せず、候補者に質問して答えさせる
- 候補者が詰まったときはヒントを段階的に出し、回答を導く
- エッジケース、代替解法、トレードオフなどを質問形式で議論する
- コード完成後、計算量の質問に加えてフォローアップクエスチョンを2〜3問出す（代替解法、エッジケース、実務での注意点、関連問題への応用など）
