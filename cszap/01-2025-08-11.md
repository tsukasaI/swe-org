## Abstract Data Type

Abstract Data Type is not specified data type such like array, queue, heap, linked-list.

Kind of interface in Go, and abstract class in most languages.

```go
type Store interface {
	Insert(key string, v any) error
	Delete(key string) error
	Find(key string) (any, error)
}

type store struct{}

// implement Store interface methods
func (s *store)Insert(key string, v any) error {
	return nil
}

func (s *store)Delete(key string) error {
	return nil
}

func (s *store)Find(key string) (any, error) {
	return nil, nil
}


func doSomething() {
	var s Store = *store{}

	if err := s.Insert("a", struct{}{}); err != nil {
		return
	}

	val, err := s.Find("a")
	if err != nil {
		return
	}

	if err := s.Delete("a"); err != nil {
		return
	}
}
```
